## Project Overview

- Developed an ESP32-based controller for a cassette deck.
- Implemented custom firmware to control cassette deck functions.
- Integrated the ESP32 with the existing cassette deck hardware.
- Developed embedded control logic for reliable operation.
- Worked on hardware integration and firmware development.
- Tested the controller for proper functionality and response.
- Combined a classic cassette deck with modern ESP32-based control.
